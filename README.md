# Duo Enceintes (Android 8+)

## Obtenir l'APK
Option A – GitHub (sans rien installer) :
1. Créez un dépôt GitHub et envoyez-y tout ce dossier.
2. Onglet « Actions » > « Build APK » > téléchargez l'artefact « DuoEnceintes-apk » (app-debug.apk).

Option B – Android Studio : ouvrir le dossier, puis Build > Build APK(s).

Installez ensuite l'APK (autoriser les sources inconnues).
